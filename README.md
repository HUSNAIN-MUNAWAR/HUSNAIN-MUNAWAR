## Engineering Profile

I design and build end-to-end AI systems that go beyond model demos. My work combines machine learning and computer vision with reliable APIs, databases, dashboards, evaluation pipelines, policy controls, observability, testing, deployment, and technical documentation.

My main interests are:

- **Computer Vision:** detection, tracking, OCR, video intelligence, inspection and edge deployment
- **Production AI:** agents, RAG, document intelligence, evaluation, safety and human approval workflows
- **Backend Engineering:** FastAPI services, PostgreSQL data models, Redis queues, authentication and auditability
- **Full-Stack Systems:** Next.js operations dashboards connected to real application workflows
- **Engineering Quality:** reproducible demos, tests, CI, architecture diagrams, runbooks and measurable proof
