## Engineering signature

- Evidence before claims: run the model or rule path, preserve outputs, and report what was unavailable.
- Product before demo: connect inference to APIs, storage, review states, exports, and operator decisions.
- Reliability by design: test failure paths, constrain side effects, scan secrets, and keep reproducible setup instructions.
